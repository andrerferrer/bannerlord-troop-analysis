# Earlier-evidence compatibility decision

No earlier committed combat-observation batch contains a Stark Sworn Sword row
that resolves exactly to `stark_swornsword` and also matches the Realm of
Thrones track/version, player side, battle context, result state, and count
fields required for a safe join. The current field and siege-attack estimates
therefore remain standalone.

No source batch or battle ID was joined. This is an explicit compatibility
decision, not an assumption that every earlier aggregate is interchangeable.
`compatibility_decision.json` is the machine-readable record.
