Thrones audits. `candidate_evidence_comparison.csv`, `COMPATIBILITY.md`, and

Captain-signature candidates without modifying frozen models.

runs have one identical, pre-existing unrelated assertion-message failure; all
other tests pass.

## Reproduction

The immutable Phase 1 consolidation uses equivalent schema names that differ
from the current generic analyzer contract. `normalized_schema_adapter.json`
records the exact value-preserving temporary transformation. Reproduce in a
disposable work directory; do not edit Phase 1 files:

```bash
batch='data/combat_observations/2026-08-21-lannister-prideknight-mixed'
work_dir=$(mktemp -d /tmp/bannerlord-analysis.XXXXXX)
archive="$work_dir/lannister_prideknight_mixed_2026-08-21.tar.xz"
base64 --decode \
  "$batch/bundle/lannister_prideknight_mixed_2026-08-21.tar.xz.base64.part-00" \
  > "$archive"
printf '%s  %s\n' \
  '1ff30bba3440c89a338cbbdbe9a78c76f0eaf912bae2d5504ee9f05f42d82456' \
  "$archive" | sha256sum --check
mkdir "$work_dir/input"
tar -xJf "$archive" -C "$work_dir/input"
```

Copy the reconstructed directory to a disposable analyzer input, apply only the
two transformations recorded in `normalized_schema_adapter.json`, and run
`scripts/analysis/analyze_normalized_combat_batch.py` with:

- batch ID `combat_2026-08-21_lannister_prideknight_mixed`;
- identity root `data/realm_of_thrones/audit`;
- normalization commit `6b9911f564832baffdb88d7c0de333a0f907b860`;
- archive SHA-256 above;
- combined source SHA-256
  `62aa7f249e53ae5747cd9a30b44b9fdab957a9f9db8674bd28639be78e1266bb`;
- 5 battles / 20 deployed gate, 10,000 bootstrap repetitions;
- focus slug `lannister_prideknight`.

The exact-image review decisions and next-test recommendation are reviewed Phase
2 additions and are not regenerated by the generic baseline command.
